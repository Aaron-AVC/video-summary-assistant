## Reproduction and checks

From a clean fixed-source worktree with Bun `1.2.5` and Node `24.19.0`, run `bun install --frozen-lockfile`; retain a new, external evidence path, then run the following build command with the preserved preload copied from this change. The recorded identity is specific to the audited result; do not relabel a rebuild or re-pin generated evidence without reviewing it.

```powershell
$env:VSA_PR23_GRAPH_PATH = '<new external graph path>'
node --require '<absolute path>/capture-parcel-build-graph.cjs' ./node_modules/plasmo/bin/index.mjs build
```

Use the commands in the repository notices index for byte verification and preview generation. For the fixed record, CLI `scope` checks committed evidence, `scope --artifact <dir>` additionally compares every built file, and `verify <dir>` compares all generated files against inputs and rejects missing, altered or unplanned files. An audit preview exit 0 means its files are valid, while `--candidate` remains blocked. This change does not wire those files into the final ZIP or run the Chrome browser gate.
